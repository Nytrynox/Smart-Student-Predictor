# Smart Student Predictor

Machine learning system that predicts student academic performance based on grades, attendance, and behavioral features.

## Features

- Multi-feature student performance modeling
- Classification into performance tiers (at-risk, average, high-performing)
- Feature importance analysis
- Interactive prediction dashboard
- Model comparison (Random Forest, XGBoost, Logistic Regression)

## Tech Stack

Python, Scikit-learn, Pandas, Streamlit, Matplotlib

## Getting Started

### Prerequisites

- Python 3.8+
- pip

### Installation

```bash
git clone https://github.com/karthik-idikuda/Smart-Student-Predictor.git
cd Smart-Student-Predictor
pip install -r requirements.txt
```

### Usage

```bash
streamlit run app.py
```
